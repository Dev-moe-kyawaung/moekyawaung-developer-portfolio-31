# Security Policy

## Supported Versions

Security updates are currently provided for the latest version on the default branch.

| Version | Supported |
|---|---|
| Latest | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately by email:

**YOUR_SECURITY_EMAIL**

Include the following information:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Relevant screenshots, logs, or proof of concept.
- Suggested remediation, if available.

Please do not disclose the vulnerability publicly until it has been reviewed and resolved.

You should receive an acknowledgement within 7 days. A security fix or further update will be provided after the issue has been investigated.

## Security Guidelines

- Never commit API keys, tokens, passwords, or private certificates.
- Store secrets in environment variables.
- Keep dependencies updated.
- Review third-party packages before installation.
- Use Dependabot or another dependency monitoring service.
