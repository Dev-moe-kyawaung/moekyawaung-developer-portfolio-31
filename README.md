A modern, responsive, and theme-driven developer portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

The website presents professional experience, technical skills, selected projects, certifications, contact information, and downloadable resume resources through a fast and accessible interface.

## Features

- Responsive layout for mobile, tablet, and desktop screens.
- Modern developer portfolio sections.
- Dark, futuristic, and cyberpunk-inspired visual direction.
- Theme-driven styling using CSS variables and Tailwind CSS.
- Smooth page transitions and UI animations with Framer Motion.
- Project showcase with technology tags and live-source links.
- Skills, experience, education, and certification sections.
- Downloadable resume/CV support.
- SEO metadata and social sharing metadata.
- Accessible navigation and semantic HTML.
- Optimized images and responsive media.
- Contact and social media links.
- Easy deployment through Vercel or Cloudflare Pages.

## Getting Started

### Requirements

- Node.js 20 or later
- npm, pnpm, yarn, or Bun
- Git

### Installation

```bash
git clone [https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-31.git](https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-31.git)

cd moekyawaung-developer-portfolio-31

npm install
```
